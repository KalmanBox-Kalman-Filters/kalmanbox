# Kalman Filter: Theory and Derivation

This page provides a self-contained, mathematically rigorous treatment of the Kalman
filter. It covers the filtering problem, two independent derivations of the algorithm
(BLUP and Bayesian), optimality theory, the prediction-error log-likelihood, the
steady-state filter, the discrete Riccati equation, and convergence. Companion pages
are [State-space foundations](state-space-theory.md),
[Smoothing theory](smoothing-theory.md), [Likelihood](mle-theory.md), and
the user-facing [Kalman filter guide](../user-guide/kalman/kalman-filter.md).

---

## 1. State-Space Model and Notation

We adopt the **Durbin & Koopman (2012)** convention throughout.

**Observation equation:**

$$y_t = Z_t \alpha_t + d_t + \varepsilon_t, \qquad \varepsilon_t \sim N(0, H_t) \tag{1}$$

**State transition equation:**

$$\alpha_{t+1} = T_t \alpha_t + c_t + R_t \eta_t, \qquad \eta_t \sim N(0, Q_t) \tag{2}$$

for $t = 1, \ldots, T$. The dimensions are:

| Symbol | Size | Interpretation |
|:-------|:-----|:---------------|
| $y_t$ | $p \times 1$ | Observed vector |
| $\alpha_t$ | $m \times 1$ | Latent state vector |
| $Z_t$ | $p \times m$ | Design (observation) matrix |
| $T_t$ | $m \times m$ | Transition (companion) matrix |
| $R_t$ | $m \times r$ | Disturbance-selection matrix |
| $H_t$ | $p \times p$ | Observation noise covariance ($\geq 0$) |
| $Q_t$ | $r \times r$ | State noise covariance ($\geq 0$) |
| $d_t$ | $p \times 1$ | Observation offset |
| $c_t$ | $m \times 1$ | State offset |

**Assumptions:**

- $\varepsilon_t$, $\eta_t$, and $\alpha_1$ are mutually independent.
- $\alpha_1 \sim N(a_1, P_1)$ with $a_1$ and $P_1$ specified (see Section 4).
- All system matrices may be time-varying but are assumed known at time $t$.

We write $\mathcal{Y}_t = \{y_1, \ldots, y_t\}$ for the information set up to time $t$,
with $\mathcal{Y}_0 = \emptyset$.

!!! note "Parameter-dependent matrices"
    In estimation contexts the system matrices depend on an unknown parameter vector
    $\theta$. The filter below is written for fixed, known matrices; the log-likelihood
    derived in Section 6 is then a function of $\theta$ and is maximised numerically.
    See [mle-theory.md](mle-theory.md) for details.

## 2. The Filtering Problem

The **filtering problem** is to compute, sequentially and recursively, the
**conditional mean** and **conditional covariance** of $\alpha_t$ given all
observations up to and including time $t$:

$$a_{t|t} = E[\alpha_t \mid \mathcal{Y}_t] \tag{3}$$

$$P_{t|t} = \operatorname{Var}(\alpha_t \mid \mathcal{Y}_t)
          = E[(\alpha_t - a_{t|t})(\alpha_t - a_{t|t})' \mid \mathcal{Y}_t] \tag{4}$$

We also require the **one-step-ahead prediction**:

$$a_{t|t-1} = E[\alpha_t \mid \mathcal{Y}_{t-1}], \qquad
P_{t|t-1} = \operatorname{Var}(\alpha_t \mid \mathcal{Y}_{t-1}) \tag{5}$$

Under Gaussianity the conditional distribution is fully characterised by its first two
moments, so equations (3)–(5) constitute a complete solution to the filtering problem.

!!! theorem "The Filtering Problem (Formal Statement)"
    Let $\{y_t\}$ be generated by (1)–(2) with Gaussian disturbances. The filtering
    problem is to compute the sequence of conditional distributions

    $$p(\alpha_t \mid \mathcal{Y}_t), \quad t = 1, \ldots, T,$$

    sequentially and in closed form. Under the Gaussian assumption this reduces to
    tracking $(a_{t|t}, P_{t|t})$ via a finite-dimensional recursion — the Kalman
    filter.

## 3. BLUP Derivation: Best Linear Unbiased Predictor

The BLUP derivation establishes the Kalman update equations without invoking
Gaussianity: they hold for any distribution with finite second moments, provided we
restrict to **linear** estimators.

### 3.1 Setup

Suppose we have the one-step-ahead prediction $a_{t|t-1}$ and $P_{t|t-1}$, obtained
by propagating the state through the transition equation. Upon observing $y_t$ we wish
to form an improved estimate

$$\hat\alpha_t = a_{t|t-1} + G_t (y_t - Z_t a_{t|t-1} - d_t) \tag{6}$$

for some **gain matrix** $G_t \in \mathbb{R}^{m \times p}$ to be chosen optimally.

**Define the prediction error (innovation):**

$$v_t = y_t - Z_t a_{t|t-1} - d_t \tag{7}$$

The innovation satisfies $E[v_t \mid \mathcal{Y}_{t-1}] = 0$ because
$E[y_t \mid \mathcal{Y}_{t-1}] = Z_t a_{t|t-1} + d_t$, so every linear update of the
form (6) is unbiased.

### 3.2 Innovation Covariance

$$\operatorname{Var}(v_t \mid \mathcal{Y}_{t-1}) = Z_t P_{t|t-1} Z_t' + H_t \equiv F_t \tag{8}$$

*Derivation:* write $v_t = Z_t(\alpha_t - a_{t|t-1}) + \varepsilon_t$. Since
$\varepsilon_t \perp \mathcal{Y}_{t-1}$ and
$\operatorname{Var}(\alpha_t - a_{t|t-1}) = P_{t|t-1}$:

$$F_t = Z_t P_{t|t-1} Z_t' + H_t.$$

Note $F_t > 0$ whenever $H_t > 0$ (or when the observable subspace is not degenerate).

### 3.3 Mean Squared Error of the Updated Estimate

The estimation error of $\hat\alpha_t$ in (6) is:

$$
\alpha_t - \hat\alpha_t
= (\alpha_t - a_{t|t-1}) - G_t v_t
= e_t - G_t v_t,
$$

where $e_t = \alpha_t - a_{t|t-1}$ is the prediction error with
$\operatorname{Var}(e_t) = P_{t|t-1}$.

The cross-covariance between $e_t$ and $v_t$ is:

$$
\operatorname{Cov}(e_t, v_t) = E[e_t v_t'] = E[(\alpha_t - a_{t|t-1})(Z_t e_t + \varepsilon_t)']
= P_{t|t-1} Z_t'. \tag{9}
$$

Therefore the mean squared error (MSE) matrix of $\hat\alpha_t$ is:

$$
P_{t|t}(G_t) = \operatorname{Var}(e_t - G_t v_t)
= P_{t|t-1} - G_t Z_t P_{t|t-1} - P_{t|t-1} Z_t' G_t' + G_t F_t G_t'. \tag{10}
$$

### 3.4 Optimal Gain by Differentiation

To minimise $\operatorname{tr}(P_{t|t}(G_t))$ over $G_t$, differentiate (10) with
respect to $G_t$ and set to zero:

$$
\frac{\partial}{\partial G_t}\operatorname{tr}(P_{t|t}) =
-2 P_{t|t-1} Z_t' + 2 G_t F_t = 0.
$$

Solving:

$$
\boxed{K_t = P_{t|t-1} Z_t' F_t^{-1}} \tag{11}
$$

This is the **Kalman gain**. Since $F_t > 0$, the solution is unique. Substituting
$G_t = K_t$ back into (10) gives the **updated covariance**:

$$
P_{t|t} = P_{t|t-1} - K_t F_t K_t' = (I - K_t Z_t) P_{t|t-1}. \tag{12}
$$

!!! theorem "BLUP Theorem"
    Among all linear unbiased estimators of the form (6), the choice $G_t = K_t$
    defined by (11) minimises $\operatorname{tr}(P_{t|t})$. Moreover, it minimises
    the entire MSE matrix in the Loewner partial order:

    $$P_{t|t}(G_t) - P_{t|t}(K_t) = (G_t - K_t) F_t (G_t - K_t)' \geq 0$$

    for every $G_t$, with equality if and only if $G_t = K_t$.

!!! proof "Proof of the Loewner inequality"
    Expand $P_{t|t}(G_t)$ as defined in (10). Add and subtract $K_t F_t K_t'$:

    $$P_{t|t}(G_t) = (I - G_t Z_t) P_{t|t-1} (I - G_t Z_t)' + G_t H_t G_t'.$$

    Writing $G_t = K_t + \Delta$ and expanding around $K_t$:

    $$P_{t|t}(G_t) = P_{t|t}(K_t) + \Delta F_t \Delta'.$$

    Since $F_t > 0$ we have $\Delta F_t \Delta' \geq 0$, with equality iff $\Delta = 0$.

## 4. Bayesian Derivation: Gaussian Posterior

The Bayesian derivation provides a complementary perspective and confirms that under
Gaussianity the Kalman update coincides with the posterior mean — making it not just
the best linear but the globally optimal estimator (see Section 5).

### 4.1 Prior at Time $t$

Assume that the prediction distribution is Gaussian:

$$\alpha_t \mid \mathcal{Y}_{t-1} \sim N(a_{t|t-1},\; P_{t|t-1}). \tag{13}$$

(This is verified inductively: it holds at $t = 1$ by assumption, and the Gaussian
family is closed under linear transformations and convolutions.)

### 4.2 Likelihood at Time $t$

Conditional on $\alpha_t$, the observation equation (1) gives:

$$y_t \mid \alpha_t \sim N(Z_t \alpha_t + d_t,\; H_t). \tag{14}$$

### 4.3 Joint Distribution

Collecting (13) and (14), the joint distribution of $(\alpha_t', y_t')'$ given
$\mathcal{Y}_{t-1}$ is Gaussian. Compute the joint moments:

$$
E\begin{pmatrix} \alpha_t \\ y_t \end{pmatrix} \Bigg| \mathcal{Y}_{t-1}
= \begin{pmatrix} a_{t|t-1} \\ Z_t a_{t|t-1} + d_t \end{pmatrix}
\tag{15}
$$

$$
\operatorname{Var}\begin{pmatrix} \alpha_t \\ y_t \end{pmatrix} \Bigg| \mathcal{Y}_{t-1}
= \begin{pmatrix} P_{t|t-1} & P_{t|t-1} Z_t' \\ Z_t P_{t|t-1} & F_t \end{pmatrix}
\tag{16}
$$

where $F_t = Z_t P_{t|t-1} Z_t' + H_t$ as defined in (8), and the off-diagonal block
follows from $\operatorname{Cov}(\alpha_t, y_t) = \operatorname{Cov}(\alpha_t,
Z_t \alpha_t + \varepsilon_t) = P_{t|t-1} Z_t'$.

### 4.4 Gaussian Conditioning Formula

For a jointly Gaussian vector $(u', w')' \sim N(\mu, \Sigma)$ with

$$\mu = \begin{pmatrix}\mu_u \\ \mu_w\end{pmatrix}, \quad
\Sigma = \begin{pmatrix}\Sigma_{uu} & \Sigma_{uw} \\ \Sigma_{wu} & \Sigma_{ww}\end{pmatrix},$$

the conditional distribution of $u$ given $w$ is:

$$u \mid w \sim N\!\left(\mu_u + \Sigma_{uw} \Sigma_{ww}^{-1}(w - \mu_w),\;
\Sigma_{uu} - \Sigma_{uw} \Sigma_{ww}^{-1} \Sigma_{wu}\right). \tag{17}$$

### 4.5 Posterior: the Kalman Update

Applying (17) to the joint (15)–(16) with $u = \alpha_t$, $w = y_t$:

$$
\alpha_t \mid \mathcal{Y}_t \sim N(a_{t|t},\; P_{t|t}) \tag{18}
$$

where:

$$
a_{t|t} = a_{t|t-1} + P_{t|t-1} Z_t' F_t^{-1} (y_t - Z_t a_{t|t-1} - d_t)
        = a_{t|t-1} + K_t v_t \tag{19}
$$

$$
P_{t|t} = P_{t|t-1} - P_{t|t-1} Z_t' F_t^{-1} Z_t P_{t|t-1}
        = (I - K_t Z_t) P_{t|t-1} \tag{20}
$$

!!! theorem "Bayesian Derivation"
    Under the Gaussian state-space model (1)–(2), the posterior distribution of
    $\alpha_t$ given $\mathcal{Y}_t$ is exactly Gaussian with mean and covariance
    given by (19)–(20). The Kalman gain $K_t$ emerges as the Gaussian conditioning
    coefficient and is identical to the BLUP gain derived in Section 3.

!!! note "Connection between derivations"
    Both derivations produce the same gain $K_t = P_{t|t-1} Z_t' F_t^{-1}$ and
    covariance update $P_{t|t} = (I - K_t Z_t) P_{t|t-1}$. The BLUP derivation
    requires only finite second moments; the Bayesian derivation yields the full
    posterior under Gaussianity. When Gaussianity holds, the Kalman filter is not
    merely the best linear estimator — it is the optimal estimator among all
    (possibly non-linear) functions of $\mathcal{Y}_t$ (Section 5).

## 5. Complete Kalman Filter Algorithm

### 5.1 Initialization

Choose initial conditions $a_1$ and $P_1$:

- **Stationary initialization:** if $T$ is stable (all eigenvalues inside the unit
  disc), solve the discrete Lyapunov equation $P_1 = T P_1 T' + R Q R'$ for $P_1$,
  which has a unique positive-semidefinite solution.
- **Diffuse initialization:** set $a_1 = 0$, $P_1 = \kappa I_m$ with
  $\kappa \to \infty$. In practice $\kappa = 10^6$ or larger; see the exact diffuse
  treatment in [diffuse-initialization.md](../user-guide/kalman/diffuse-initialization.md).
- **Informative prior:** set $a_1$ and $P_1$ directly from domain knowledge.

### 5.2 Recursion

For $t = 1, \ldots, T$, given $a_{t|t-1}$ and $P_{t|t-1}$:

=== "Prediction"

    The one-step-ahead prediction propagates the state through the transition equation.
    At $t = 1$ these are simply the initial conditions; for $t \geq 2$:

    $$a_{t|t-1} = T_{t-1} a_{t-1|t-1} + c_{t-1} \tag{P1}$$

    $$P_{t|t-1} = T_{t-1} P_{t-1|t-1} T_{t-1}' + R_{t-1} Q_{t-1} R_{t-1}' \tag{P2}$$

    **Interpretation:** $a_{t|t-1}$ is the best prediction of $\alpha_t$ from
    $\mathcal{Y}_{t-1}$. The uncertainty $P_{t|t-1}$ grows by $R_{t-1} Q_{t-1}
    R_{t-1}'$, reflecting fresh state noise introduced at step $t-1$.

=== "Innovation"

    The innovation $v_t$ is the part of $y_t$ not predictable from $\mathcal{Y}_{t-1}$:

    $$v_t = y_t - Z_t a_{t|t-1} - d_t \tag{I1}$$

    $$F_t = Z_t P_{t|t-1} Z_t' + H_t \tag{I2}$$

    $F_t$ is the innovation covariance. Compute the Cholesky factor $L_t$ such that
    $F_t = L_t L_t'$ for numerical efficiency when solving $F_t^{-1} v_t$.

=== "Gain and Update"

    **Kalman gain:**

    $$K_t = P_{t|t-1} Z_t' F_t^{-1} \tag{U1}$$

    **Filtered state:**

    $$a_{t|t} = a_{t|t-1} + K_t v_t \tag{U2}$$

    **Filtered covariance (standard form):**

    $$P_{t|t} = (I - K_t Z_t) P_{t|t-1} \tag{U3}$$

    **Filtered covariance (Joseph form — numerically stable):**

    $$P_{t|t} = (I - K_t Z_t) P_{t|t-1} (I - K_t Z_t)' + K_t H_t K_t' \tag{U4}$$

    Equation (U4) preserves symmetry and positive semi-definiteness even in
    finite-precision arithmetic; see [numerical-stability.md](numerical-stability.md).

=== "Forecast"

    At the end of each cycle, the one-step-ahead forecast for period $t+1$ and its
    MSE are already determined by running prediction (P1)–(P2) with
    $a_{t+1|t} = T_t a_{t|t} + c_t$ and $P_{t+1|t} = T_t P_{t|t} T_t' + R_t Q_t
    R_t'$. For $h$-step-ahead forecasts $a_{t+h|t}$, iterate the prediction step
    $h$ times starting from the filtered state $a_{t|t}$, replacing $Q$ by $0$ when
    $h > 1$ (no new measurements).

### 5.3 Summary Table

| Quantity | Formula | Equation |
|:---------|:--------|:---------|
| Prediction | $a_{t\|t-1} = T_{t-1} a_{t-1\|t-1} + c_{t-1}$ | (P1) |
| Prediction MSE | $P_{t\|t-1} = T_{t-1} P_{t-1\|t-1} T_{t-1}' + R_{t-1}Q_{t-1}R_{t-1}'$ | (P2) |
| Innovation | $v_t = y_t - Z_t a_{t\|t-1} - d_t$ | (I1) |
| Innovation var | $F_t = Z_t P_{t\|t-1} Z_t' + H_t$ | (I2) |
| Kalman gain | $K_t = P_{t\|t-1} Z_t' F_t^{-1}$ | (U1) |
| Filtered state | $a_{t\|t} = a_{t\|t-1} + K_t v_t$ | (U2) |
| Filtered MSE | $P_{t\|t} = (I - K_t Z_t) P_{t\|t-1}$ | (U3) |

## 6. Optimality Properties

### 6.1 Global Optimality Under Gaussianity

!!! theorem "MMSE Optimality (Kalman, 1960)"
    Let the state-space model (1)–(2) hold with Gaussian disturbances and initial
    condition $\alpha_1 \sim N(a_1, P_1)$. Then the Kalman filter is the
    **minimum mean square error (MMSE) estimator** of $\alpha_t$ given $\mathcal{Y}_t$
    among all measurable functions of $\mathcal{Y}_t$, not just linear ones:

    $$E[\|\alpha_t - \hat\alpha_t\|^2 \mid \mathcal{Y}_t] \geq E[\|\alpha_t - a_{t|t}\|^2 \mid \mathcal{Y}_t]$$

    for every estimator $\hat\alpha_t = g(\mathcal{Y}_t)$.

!!! proof "Proof sketch"
    The MMSE estimator in any Bayesian model is the posterior mean
    $E[\alpha_t \mid \mathcal{Y}_t]$. Under Gaussianity, the posterior computed in
    Section 4 is exactly $N(a_{t|t}, P_{t|t})$, so the posterior mean is $a_{t|t}$.
    No estimator can improve upon the posterior mean in MSE without additional information.

    Furthermore, under Gaussianity the MAP (maximum a posteriori) estimator coincides
    with the posterior mean because the Gaussian distribution is unimodal and symmetric.
    Thus MMSE = MAP = $a_{t|t}$.

### 6.2 Innovation Properties

!!! theorem "Innovation White-Noise Property"
    Let $v_t = y_t - Z_t a_{t|t-1} - d_t$ be the sequence of innovations. Under the
    Gaussian state-space model:

    1. $E[v_t \mid \mathcal{Y}_{t-1}] = 0$ — the innovations form a
       **martingale difference sequence**.
    2. $\operatorname{Cov}(v_t, v_s) = 0$ for $t \neq s$ — the innovations are
       **serially uncorrelated**.
    3. $\operatorname{Var}(v_t) = F_t$.
    4. Under Gaussianity, $v_t \mid \mathcal{Y}_{t-1} \sim N(0, F_t)$, and the
       innovations are mutually **independent** across time.

The innovation whiteness property is exploited directly in Section 7 to
build the prediction-error log-likelihood and provides the basis for
**filter diagnostic tests**: any autocorrelation or heteroskedasticity in the
standardised innovations $F_t^{-1/2} v_t$ signals model misspecification.

### 6.3 Monotone Uncertainty Reduction

!!! theorem "Uncertainty Reduction"
    At every time point, incorporating the observation $y_t$ never increases
    uncertainty:

    $$P_{t|t} \leq P_{t|t-1} \quad (\text{Loewner order})$$

    with equality if and only if $Z_t = 0$ (no new information).

!!! proof "Proof"
    From (12): $P_{t|t-1} - P_{t|t} = K_t F_t K_t' = P_{t|t-1} Z_t' F_t^{-1} Z_t
    P_{t|t-1} \geq 0$ as a product of positive-semidefinite matrices. Equality holds
    iff $K_t = 0$, which requires $P_{t|t-1} Z_t' = 0$, i.e., the observable
    combination $Z_t \alpha_t$ has zero prior variance.

### 6.4 Consistency

Under standard observability and stabilizability conditions (Section 9), the filtered
estimate is consistent in the following sense: as the number of observations $T \to
\infty$ in a time-invariant system, $P_{t|t} \to P_\infty$ geometrically fast (see
Section 8), and the posterior distribution concentrates around the true state trajectory.

## 7. Prediction-Error Decomposition and Log-Likelihood

One of the most computationally attractive features of the Kalman filter is that the
**exact log-likelihood** of the observation sequence is obtained as a byproduct of a
single forward pass — no additional computation is required.

### 7.1 Factorisation

By the chain rule of conditional probabilities:

$$p(y_{1:T} \mid \theta) = \prod_{t=1}^{T} p(y_t \mid \mathcal{Y}_{t-1}, \theta) \tag{21}$$

Each factor $p(y_t \mid \mathcal{Y}_{t-1})$ is the marginal distribution of $y_t$
integrating out $\alpha_t$. Since

$$y_t \mid \mathcal{Y}_{t-1} = Z_t \alpha_t + d_t + \varepsilon_t, \quad
\alpha_t \mid \mathcal{Y}_{t-1} \sim N(a_{t|t-1}, P_{t|t-1}),$$

the marginal is also Gaussian:

$$y_t \mid \mathcal{Y}_{t-1} \sim N(Z_t a_{t|t-1} + d_t,\; F_t). \tag{22}$$

Equivalently, $v_t = y_t - Z_t a_{t|t-1} - d_t \sim N(0, F_t)$.

### 7.2 Contribution of Each Observation

$$\log p(y_t \mid \mathcal{Y}_{t-1}) = -\frac{1}{2}\left[
  p \log 2\pi + \log \det F_t + v_t' F_t^{-1} v_t
\right] \tag{23}$$

### 7.3 Full Log-Likelihood

Summing over $t = 1, \ldots, T$:

$$
\boxed{
\ell(\theta) = \log p(y_{1:T} \mid \theta) = -\frac{1}{2} \sum_{t=1}^{T}
\left[ p \log 2\pi + \log \det F_t + v_t' F_t^{-1} v_t \right]
}
\tag{24}
$$

!!! note "No extra cost"
    The quantities $v_t$ and $F_t$ are already computed during the filter pass
    (equations I1–I2). Evaluating $\ell(\theta)$ adds only the cost of computing
    $\log \det F_t$ (via the Cholesky factor of $F_t$, which is needed anyway for
    the back-solve $F_t^{-1} v_t$) and the scalar inner product $v_t' F_t^{-1} v_t$.
    The total incremental cost is $O(p^3)$ per time step.

!!! tip "Concentrated likelihood"
    For models where $H_t = \sigma^2 \tilde H_t$ or $Q_t = \sigma^2 \tilde Q_t$ for
    a single scaling factor $\sigma^2$, the concentrated log-likelihood can be formed
    by analytically maximising over $\sigma^2$ at each numerical optimisation step,
    reducing the effective parameter space by one. See [mle-theory.md](mle-theory.md).

### 7.4 Missing Observations

If $y_t$ is missing (or partially observed), the corresponding term in (24) is simply
omitted and the filter proceeds with $a_{t|t} = a_{t|t-1}$,
$P_{t|t} = P_{t|t-1}$ (no update). The log-likelihood is accumulated only over
observed time points. Full details are in
[missing-data.md](../user-guide/kalman/missing-data.md).

## 8. Steady-State Kalman Filter

When the system matrices are **time-invariant** — $Z_t \equiv Z$, $T_t \equiv T$,
$R_t \equiv R$, $Q_t \equiv Q$, $H_t \equiv H$ — and certain algebraic conditions
hold, the sequence $\{P_{t|t-1}\}$ converges to a fixed matrix $P_\infty$. Once
convergence is achieved, the Kalman gain becomes constant ($K_\infty$) and the
update equations simplify substantially.

### 8.1 Existence Conditions

!!! theorem "Steady-State Existence"
    The sequence $P_{t|t-1}$ converges to the unique positive-semidefinite solution
    $P_\infty$ of the **Algebraic Discrete Riccati Equation** (ADRE) if and only if:

    1. $(T, Z)$ is **detectable**: there is no unstable unobservable mode, i.e.,
       every eigenvalue $\lambda$ of $T$ with $|\lambda| \geq 1$ is observable.
    2. $(T, R Q^{1/2})$ is **stabilizable**: every unstable mode can be reached by
       state noise, i.e., there is no unstable mode orthogonal to the range of
       $R Q^{1/2}$.

    When both conditions hold, $P_\infty \geq 0$ exists, is unique, and convergence
    is geometric.

### 8.2 Algebraic Riccati Equation

The steady-state prediction covariance $P_\infty$ satisfies:

$$P_\infty = T P_\infty T' + R Q R' - T P_\infty Z' (Z P_\infty Z' + H)^{-1} Z P_\infty T'
\tag{25}$$

This is the fixed-point of the **discrete Riccati recursion** (Section 9.1) and is
known as the Discrete Algebraic Riccati Equation (DARE).

**Steady-state gain:**

$$K_\infty = P_\infty Z' (Z P_\infty Z' + H)^{-1} = P_\infty Z' F_\infty^{-1}
\tag{26}$$

where $F_\infty = Z P_\infty Z' + H$.

**Steady-state filtered covariance:**

$$P_{\infty|t} = (I - K_\infty Z) P_\infty \tag{27}$$

### 8.3 Convergence Rate

The convergence of $P_{t|t-1}$ to $P_\infty$ is governed by the **closed-loop
transition matrix**:

$$\Phi_\infty = T(I - K_\infty Z) \tag{28}$$

The spectral radius $\rho(\Phi_\infty) < 1$ under the detectability condition,
guaranteeing geometric convergence:

$$\|P_{t|t-1} - P_\infty\| = O(\rho(\Phi_\infty)^t) \tag{29}$$

In practice, convergence to machine precision typically occurs within a few multiples
of the dominant time constant $1 / |\log \rho(\Phi_\infty)|$.

### 8.4 Computational Advantage

Once $P_\infty$ and $K_\infty$ are available (computed offline by iterating the
Riccati recursion or solving the DARE directly), the online filter reduces to:

$$v_t = y_t - Z a_{t|t-1} - d, \qquad a_{t|t} = a_{t|t-1} + K_\infty v_t \tag{30}$$

$$a_{t+1|t} = T a_{t|t} + c \tag{31}$$

No matrix multiplications involving $P$ are needed during the forward pass — only
matrix-vector products. This reduces the per-step cost from $O(m^3 + m^2 p)$ to
$O(m^2)$ (or $O(mp)$ if $m \gg p$).

!!! tip "When to use the steady-state filter"
    Use the steady-state filter when: (i) the system is time-invariant, (ii)
    $P_{t|t-1}$ has visibly converged (inspect the trace or Frobenius norm), and
    (iii) $T \gg m$ so that the saved computation per step is significant. The
    kalmanbox `SteadyStateFilter` class automates this switchover.

## 9. Discrete Riccati Equation

The prediction covariance $P_{t|t-1}$ satisfies the **Discrete Riccati Recursion**
(DRR), which plays a central role in filter analysis and the derivation of the
steady-state filter.

### 9.1 Forward Riccati Recursion

Combining the prediction step (P2) and the update (U3):

$$P_{t+1|t} = T_t P_{t|t} T_t' + R_t Q_t R_t'
= T_t (I - K_t Z_t) P_{t|t-1} T_t' + R_t Q_t R_t' \tag{32}$$

Substituting $K_t = P_{t|t-1} Z_t' F_t^{-1}$:

$$
\boxed{
P_{t+1|t} = T_t P_{t|t-1} T_t' + R_t Q_t R_t'
- T_t P_{t|t-1} Z_t' F_t^{-1} Z_t P_{t|t-1} T_t'
}
\tag{33}
$$

This is the **Discrete Riccati Recursion**. Note that $P_{t+1|t}$ depends only on
$P_{t|t-1}$, so the covariance sequence can be pre-computed in a single offline pass
(when system matrices are known).

### 9.2 Equivalent Form via Closed-Loop Matrix

Define the closed-loop matrix $\tilde T_t = T_t(I - K_t Z_t)$. Then (33) can be
rewritten:

$$P_{t+1|t} = \tilde T_t P_{t|t-1} \tilde T_t' + T_t K_t H_t K_t' T_t' + R_t Q_t R_t' \tag{34}$$

This form is numerically preferable because $\tilde T_t P_{t|t-1} \tilde T_t'$ is
explicitly a symmetric outer product.

### 9.3 Algebraic Riccati Equation (Steady State)

At steady state, $P_{t+1|t} = P_{t|t-1} = P_\infty$, so (33) becomes the DARE (25).
The DARE can be solved efficiently via:

- **Newton's method**: quadratic convergence but requires an initial stabilizing
  solution.
- **Schur decomposition** of the associated symplectic matrix: numerically robust and
  globally convergent.
- **Doubling algorithm**: geometric convergence, efficient for large $m$.

### 9.4 Doubling Algorithm for Initialization

The doubling algorithm computes $P_\infty$ without iterating the Riccati recursion
step by step. It exploits the structure of the symplectic matrix and delivers the
steady-state solution in $O(\log \kappa)$ steps where $\kappa$ is the number of
standard recursion steps needed for convergence:

Initialize: $A_0 = T$, $G_0 = R Q R'$, $H_0 = Z' H^{-1} Z$. Then iterate:

$$A_{k+1} = A_k (I + G_k H_k)^{-1} A_k \tag{35}$$

$$G_{k+1} = G_k + A_k (I + G_k H_k)^{-1} G_k A_k' \tag{36}$$

$$H_{k+1} = H_k + A_k' H_k (I + G_k H_k)^{-1} A_k \tag{37}$$

After convergence, $P_\infty \approx G_k$ (with appropriate mapping). This is
particularly useful when $m$ is large and iterating the full Riccati recursion is
expensive.

## 10. Convergence and Filter Stability

### 10.1 Stability of the Closed-Loop System

!!! theorem "Filter Stability"
    Let $(T, Z)$ be detectable and $(T, R Q^{1/2})$ be stabilizable. Then:

    1. The closed-loop matrix $\Phi_t = T_t(I - K_t Z_t)$ has all eigenvalues
       strictly inside the unit circle for all sufficiently large $t$.
    2. The Riccati recursion (33) is globally stable: for any initial
       $P_{1|0} \geq 0$, the sequence $P_{t|t-1}$ converges to the unique
       stabilizing solution $P_\infty$ of the DARE.
    3. The filter error $e_t = \alpha_t - a_{t|t-1}$ is bounded in mean square:
       $E[\|e_t\|^2]$ remains bounded as $t \to \infty$.

!!! proof "Proof sketch (Lyapunov argument)"
    Define the Lyapunov function $V_t = \operatorname{tr}(P_{t|t-1} - P_\infty)
    \geq 0$ (valid once $P_{t|t-1} \geq P_\infty$, which can be shown to hold after
    finitely many steps under stabilizability). The Riccati recursion implies

    $$V_{t+1} \leq \rho^2 V_t$$

    for some $\rho = \rho(\Phi_\infty) < 1$, so $V_t \to 0$ geometrically. The
    detectability condition ensures $P_\infty > 0$, preventing divergence.

### 10.2 Stability Despite Unstable State Dynamics

A common misconception is that the Kalman filter requires the state transition $T$
to be stable. This is false:

!!! theorem "Stability with Unstable $T$"
    Even if $T$ has eigenvalues on or outside the unit circle (as in random walks,
    integrated processes, or non-stationary components of structural models), the
    Kalman filter remains stable provided the system is **detectable**. The
    innovations $v_t$ remain bounded in variance, and the filtered state tracks the
    true state with bounded MSE $P_{t|t}$.

**Intuition:** an unstable state transition amplifies prediction uncertainty
($P_{t|t-1}$ grows), but the Kalman gain $K_t$ grows proportionally — the filter
puts more weight on new observations and less on the prediction, exactly correcting
for the increased uncertainty. Once the observation $y_t$ is incorporated, the
filtered uncertainty $P_{t|t}$ is reduced by the information content of $y_t$.

### 10.3 Observability and Identifiability

The **observability matrix** of the pair $(T, Z)$ is:

$$\mathcal{O}_m = \begin{pmatrix} Z \\ ZT \\ ZT^2 \\ \vdots \\ ZT^{m-1} \end{pmatrix} \in \mathbb{R}^{mp \times m}
\tag{38}$$

The system is **completely observable** if $\operatorname{rank}(\mathcal{O}_m) = m$.
Under complete observability, after at most $m$ time steps all state components are
uniquely determined by the observations (in the noise-free case), and the filter
covariance $P_{t|t}$ converges to zero as $t \to \infty$ regardless of
initialization.

Under the weaker **detectability** condition, only the unstable modes need be
observable, which is sufficient for filter stability and for a finite steady-state
covariance $P_\infty$.

## 11. Worked Example: Local Level Model

To ground the theory, consider the **local level model** (Muth, 1960; Harvey, 1989):

$$y_t = \mu_t + \varepsilon_t, \quad \varepsilon_t \sim N(0, \sigma_\varepsilon^2) \tag{39}$$

$$\mu_{t+1} = \mu_t + \eta_t, \quad \eta_t \sim N(0, \sigma_\eta^2) \tag{40}$$

This is (1)–(2) with $Z = 1$, $T = 1$, $R = 1$, $H = \sigma_\varepsilon^2$,
$Q = \sigma_\eta^2$, $d = 0$, $c = 0$, $m = p = r = 1$.

### 11.1 Riccati Recursion (Scalar)

The Riccati recursion (33) becomes:

$$P_{t+1|t} = P_{t|t-1} + \sigma_\eta^2 - \frac{P_{t|t-1}^2}{P_{t|t-1} + \sigma_\varepsilon^2} \tag{41}$$

At steady state $P_{t+1|t} = P_{t|t-1} = P_\infty$, so:

$$P_\infty^2 - P_\infty \sigma_\varepsilon^2 - \sigma_\eta^2 \sigma_\varepsilon^2 = 0 \tag{42}$$

Taking the positive root:

$$P_\infty = \frac{\sigma_\varepsilon^2}{2}\left[
  -1 + \sqrt{1 + 4\frac{\sigma_\eta^2}{\sigma_\varepsilon^2}}
\right] + \frac{\sigma_\varepsilon^2}{2}
= \frac{\sigma_\varepsilon^2}{2}\left(\sqrt{1 + 4q} - 1\right) \tag{43}$$

where $q = \sigma_\eta^2 / \sigma_\varepsilon^2$ is the **signal-to-noise ratio**.

### 11.2 Steady-State Gain

$$K_\infty = \frac{P_\infty}{P_\infty + \sigma_\varepsilon^2} \tag{44}$$

As $q \to 0$ (observations are noisy), $K_\infty \to 0$ (filter ignores each new
observation). As $q \to \infty$ (state noise dominates), $K_\infty \to 1$ (filter
tracks each observation exactly).

### 11.3 Connection to Exponential Smoothing

In the steady state, the filtered state update is:

$$a_{t|t} = a_{t|t-1} + K_\infty (y_t - a_{t|t-1}) = (1 - K_\infty) a_{t|t-1} + K_\infty y_t$$

This is exactly **simple exponential smoothing** with smoothing constant $K_\infty$,
providing the state-space justification for exponential smoothing as a special case
of the Kalman filter under the local level model.
